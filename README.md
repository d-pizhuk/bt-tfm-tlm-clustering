This repository contains the notebooks with different machine learning models training and evaluation for the Bachelor thesis of Davyd Pizhuk and Daria Kuklina.

Version Compatibility for this project: 

1. Numpy 1.26.4
2. Pandas 1.3.5
3. Xport 3.6.1

Warning! Pyrenn library contains a bug. All the occurrences of dtype=np.int and dtype=np.float should be changed to just dtype=int and dtype=float accordingly in pyrenn.py (which is installed during pip install pyrenn execution).
